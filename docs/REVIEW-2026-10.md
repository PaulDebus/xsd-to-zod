### Release scope and accepted boundaries

**High: the proposed 0.4 non-breaking claim is false.** Compare
`git show v0.3.1:src/xsdBuiltins.ts` with current defaults. Integer `bigint` →
`number`, anonymous type naming, omitted optional repeated fields, async
compilation, lexical-retention defaults, validation strictness, and required
Zod peer installation already landed. Resolution: migration preview and
sequencing corrections in `docs/MIGRATION.md`, README, and the output-defaults
design document. Reverting all of these is not a review fix; publishing must
acknowledge them explicitly.

**High: do not remove generated-file imports as “internals.”**
[IRE-11](https://linear.app/ireq/issue/IRE-11/pre-10-cleanup-trim-public-api-surface-fix-cli-generate-subcommand)'s proposed
helper trim conflicts with [IRE-21](https://linear.app/ireq/issue/IRE-21/curate-the-public-export-surface-for-10-lock-in) and with `src/irToZod.ts`'s generated imports
(`xsdTotalDigits`, `xsdFractionDigits`, `xsdOrderCompare`, structured datatype
helpers, and others). Resolution: retain exports in this round. Before 1.0,
settle the export contract and inventory every generation mode, then trim/move
only deliberately. The compiler-subpath decision remains a product/API choice,
not a safe non-breaking deletion.

**Explicitly accepted:** full XSD validation remains the optional libxml2 tier;
element order/unexpected-element enforcement, lax wildcard content validation,
ID/IDREF referential checks, substitution-member-declared identity constraints,
and mixed-content interleaving are not newly promised by these fixes. Mixed
content `_text` concatenation is an existing 1.x design choice. libxml2 validates
the original mixed content; it cannot restore information lost by typed parsing.
XSD 1.1, configurable naming/config discovery, fluent builders, and decimal
arithmetic dependencies remain independently scoped feature work.

**Low: stale documentation obscures the boundary.** Removed the claim that
registry metadata is merely informational, corrected identity-constraint test
scope, and stopped promising XML byte identity from scalar lexical retention.
Documentation now explains manual schema composition and primitive QName root
namespace contexts. Migration documentation is included in the packed package.
